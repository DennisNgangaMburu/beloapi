BeloAPI.

One C++ file. Zero dependencies. Turns Airbnb's public web requests into a clean local JSON API and MCP tools for AI agents.

Download for Windows View on GitHub API reference
MIT licensed. Runs on 127.0.0.1:8787. No login, no API keys of your own.
Features

Small on purpose.

Everything you need to search stays and read Airbnb's public documents, and nothing you don't.

01

JSON API

Stays search, place autocomplete, markets, homepage feed, announcements, promotions, header, consent flags and client config.

02

MCP server

Nine tools over HTTP or stdio, so Claude, Cursor, Codex and VS Code can call them directly, with no bridge process.

03

One file

server.cpp is the entire server. No npm, no Python, no DLLs. MinGW or MSVC, then run.

04

Anonymous

No login, no cookies, no keys of your own. It only reads public data, and it refuses to bind beyond loopback unless you opt in.

05

Deployable

Bearer-token auth, CORS, public bind and an OpenAPI 3.1 document. Runs behind nginx with TLS.

06

Portable core

Windows is the released binary. Linux and macOS build from the same source.

Quick start

Three commands.

Download the Windows binary, run it, and call the API.

$ beloapi.exe
$ curl "http://127.0.0.1:8787/api/health"
$ curl "http://127.0.0.1:8787/api/search?location=Mombasa&checkin=2026-12-10&checkout=2026-12-12&adults=2"

Use a different port with beloapi.exe --port 9000. Run beloapi.exe --test to check every upstream route.

Endpoints

What it returns.

Responses are the raw Airbnb JSON documents, passed through with their original status. BeloAPI adds nothing and removes nothing.

MethodPathReturns
GET/api/healthVersion, author, uptime
GET/api/autocomplete?query=Place suggestions with place_id
GET/api/search?location=&checkin=&checkout=&adults=Stays, prices, ratings, coordinates
GET/api/marketsRegion and market mapping
GET/api/homepageCurated homepage feed
GET/api/announcementsSite-wide announcements
GET/api/promotionsPromotion slots
GET/api/headerLogged-out header menu
GET/api/consentConsent flags
GET/api/configClient configuration
GET/openapi.jsonOpenAPI 3.1 description
POST/mcpMCP over JSON-RPC 2.0

Extra query parameters: locale currency country num_results place_id children infants pets items. Full parameter tables, response field maps and error codes are in docs/API.md.

MCP

For AI agents.

Nine tools over HTTP or stdio, so Claude Desktop, Claude Code, Cursor, Codex and VS Code can search stays and look up places without screen scraping.

$ beloapi.exe --mcp-stdio

Point an MCP client at http://127.0.0.1:8787/mcp, or let it launch beloapi.exe --mcp-stdio directly. No bridge process needed.
